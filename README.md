
MiRaíz - Maquetación inicial del prototipo (HTML + CSS)

Cómo abrirlo
  Abra index.html con doble clic en Chrome, Edge o Firefox. Necesita internet solo
  para cargar las fuentes (Bitter y Atkinson Hyperlegible desde Google Fonts).

Archivos
  index.html  Estructura de la página y barra de controles del prototipo.
  styles.css  UI Kit: tokens (:root), componentes, diseño responsivo y modo wireframe.
  app.js      Pantallas, datos de ejemplo e interacciones simuladas (sin servidor).

Pantallas (rutas con #)
  #login  #registro  #inicio  #producto-1  #intereses
  #publicar  #mis-productos  #panel  #uikit
